    Cuestionario previo de saberes iniciales sobre lógica de programación y conceptos básicos antes de iniciar el módulo.

    1. Introducción a Java

    Java es un lenguaje de programación de alto nivel, orientado a objetos, robusto y multiplataforma.

    2. Antecedentes de Java

    Creado por James Gosling en Sun Microsystems (1991). Su lema rector es: "Write Once, Run Anywhere" (WORA).

    3. Frameworks: Definición y Características

    Un Framework es una estructura base estandarizada sobre la cual se desarrolla un software, facilitando tareas comunes.

    4. Frameworks e IDEs para Java

    • IDE: Entorno de desarrollo para escribir y depurar código (ej. NetBeans, IntelliJ, Eclipse).
    • Framework: Plataforma de bibliotecas y reglas (ej. Spring Boot, Jakarta EE).

    5. Configuración del Entorno

    • JDK: Kit de desarrollo con compilador (javac).
    • JRE: Entorno de ejecución de aplicaciones Java.
    • JVM: Máquina virtual que interpreta el Bytecode.

    6. Introducción a POO

    Paradigma de programación que organiza el software en torno a objetos de la vida real mediante Clases y Atributos.

    7. Pilares de la POO

    1. Abstracción: Enfocarse en características esenciales.
    2. Encapsulamiento: Proteger atributos restringiendo accesos (private).
    3. Herencia: Reutilización de código entre clases relativas.
    4. Polimorfismo: Capacidad de realizar una misma acción de distintas formas.

    8. Estructura Básica de un Programa

    public class HolaMundo {
    public static void main(String[] args) {
        System.out.println("¡Hola desde Java!");
    }
}

    9. Clases, Atributos y Métodos

    public class Persona {
    String nombre;
    void saludar() {
        System.out.println("Hola");
    }
}

    10. Instanciar Objetos

    Persona p = new Persona();
p.saludar();

    Parcial 2 – Introducción a la Programación Orientada a Objetos

    En este bloque aprenderás a modularizar aplicaciones utilizando funciones y métodos, manejar la entrada de datos dinámica del usuario, trabajar con textos, estructurar colecciones fijas mediante arreglos y aplicar los pilares centrales de Herencia y Polimorfismo.

    1. Métodos en Java

    Un método es un conjunto de instrucciones agrupadas bajo un nombre que realizan una tarea específica. Promueven la reutilización de código y la modularidad.

    • Modificador de Acceso: Define la visibilidad (public, private, protected).
    • Tipo de Retorno: Especifica el dato devuelto (int, String, etc.) o void si no retorna nada.
    • Parámetros: Variables recibidas entre paréntesis.
    public class Calculadora {
    // Método con retorno y parámetros
    public int sumar(int a, int b) {
        return a + b;
    }

    // Método sin retorno (void)
    public void mostrarMensaje(String msg) {
        System.out.println("Mensaje: " + msg);
    }
}

    2. Sobrecarga de Métodos en Java

    La Sobrecarga (Overloading) ocurre cuando en una misma clase existen dos o más métodos con el mismo nombre pero con diferente lista de parámetros (diferente cantidad o distintos tipos de datos).

    💡 Regla de Oro: El tipo de retorno por sí solo NO basta para diferenciar dos métodos sobrecargados; la firma debe cambiar en los argumentos. 
    public class Impresora {
    public void imprimir(int numero) {
        System.out.println("Número entero: " + numero);
    }

    public void imprimir(String texto) {
        System.out.println("Texto: " + texto);
    }

    public void imprimir(double n1, double n2) {
        System.out.println("Decimales: " + n1 + ", " + n2);
    }
}

    3. Constructores

    Un constructor es un método especial que se invoca automáticamente al instanciar un objeto con la palabra clave new. Se utiliza para inicializar atributos.

    • Tiene el mismo nombre exacto de la clase.
    • No posee tipo de retorno (ni siquiera void).
    • Pueden sobrecargarse (Constructor por defecto y Constructor parametrizado).
    public class Estudiante {
    private String nombre;
    private int edad;

    // Constructor Parametrizado
    public Estudiante(String nombre, int edad) {
        this.nombre = nombre;
        this.edad = edad;
    }
}

    4. Entrada de Datos por Teclado

    Java utiliza la clase Scanner pertenecente al paquete java.util para capturar datos introducidos por el usuario desde la consola estándar (System.in).

    import java.util.Scanner;

public class EntradaDatos {
    public static void main(String[] args) {
        Scanner teclado = new Scanner(System.in);

        System.out.print("Ingresa tu nombre: ");
        String nombre = teclado.nextLine();

        System.out.print("Ingresa tu edad: ");
        int edad = teclado.nextInt();

        System.out.println("Hola " + nombre + ", tienes " + edad + " años.");
    }
}

    5. Métodos de la Clase String

    Los objetos String en Java son inmutables. Poseen una amplia colección de métodos integrados para manipulación de cadenas:

    Método Descripción Ejemplo
    length() Devuelve el número total de caracteres. "Hola".length() -> 4
    charAt(int index) Devuelve el carácter en el índice especificado. "Java".charAt(0) -> 'J'
    equals(Object obj) Compara el contenido de dos cadenas exactamente. "A".equals("A") -> true
    toUpperCase() / toLowerCase() Convierte el texto a mayúsculas o minúsculas. "hola".toUpperCase() -> "HOLA"
    substring(int begin, int end) Extrae una subcadena de texto. "Código".substring(0, 3) -> "Cód"

    6. Arreglos (Arrays)

    Un arreglo es una estructura de datos estática que almacena una colección de elementos de un mismo tipo en posiciones consecutivas de memoria.

    // Declaración e inicialización de un arreglo de 5 posiciones
int[] calificaciones = new int[5];

// Asignación de valores
calificaciones[0] = 95;
calificaciones[1] = 88;

// Recorrido con un bucle for-each
for (int nota : calificaciones) {
    System.out.println("Nota: " + nota);
}

    7. Herencia y Polimorfismo en Java

    Herencia: Permite que una clase hija (subclase) adquiera atributos y métodos de una clase padre (superclase) mediante la palabra extends.

    Polimorfismo: Capacidad de objetos de distintas subclases para responder al mismo mensaje o invocación de método de manera propia usando la sobreescritura (@Override).

    // Clase Padre
class Animal {
    public void hacerSonido() {
        System.out.println("Haciendo sonido genérico...");
    }
}

// Clase Hija que hereda y aplica Polimorfismo
class Perro extends Animal {
    @Override
    public void hacerSonido() {
        System.out.println("El perro ladra: ¡Guau guau!");
    }
}

    Parcial 3 – Integración de Frameworks y Addons

    En este módulo aprenderás a diseñar e implementar Interfaces Gráficas de Usuario (GUI) ricas e interactivas utilizando la librería Java Swing, con el uso de eventos, gestores de diseño y la construcción de un proyecto integrador.

    1. Interfaz de Usuario (GUI)

    Una GUI (Graphical User Interface) reemplaza la interfaz de consola por ventanas visuales con botones, menús y cajas de texto. En Java, la biblioteca principal estándar es Swing (perteneciente al paquete javax.swing), construida sobre la base AWT.

    💡 Ventaja de Swing: Al ser un conjunto de componentes "ligeros" (Lightweight), se dibujan de manera uniforme independientemente del sistema operativo.

    2. Componentes Gráficos

    Los componentes visuales fundamentales de Swing permiten construir controles e interacciones completas:

    • JFrame: Ventana principal contenedora con barra de título y botones de cerrar/minimizar.
    • JPanel: Contenedor genérico para agrupar y organizar componentes secundarios.
    • JLabel: Muestra cadenas de texto o imágenes no editables.
    • JTextField: Caja de texto para entrada de una sola línea de datos.
    • JButton: Botón de acción interactivo que dispara eventos de clic (ActionListener).
    • JComboBox: Lista desplegable de opciones seleccionables.

    3. Métodos Fundamentales en GUI

    Principales métodos para inicializar y controlar la ejecución de componentes visuales:

    Método Uso en Swing
    setSize(int width, int height) Establece el ancho y el alto en píxeles de la ventana o componente.
    setTitle(String title) Define el texto del título en la barra superior del JFrame.
    setDefaultCloseOperation(...) Define la acción al dar clic en la 'X' (ej. JFrame.EXIT_ON_CLOSE).
    setVisible(boolean b) Muestra (true) u oculta (false) la ventana en pantalla.
    add(Component comp) Inserta un componente gráfico dentro del contenedor activo.

    4. Diseño de Interfaces Gráficas (Layout Managers)

    Los Layout Managers posicionan automáticamente los componentes según el tamaño de la ventana:

    • FlowLayout: Acomoda componentes uno al lado del otro en secuencia horizontal.
    • BorderLayout: Divide el contenedor en 5 regiones (NORTH, SOUTH, EAST, WEST, CENTER).
    • GridLayout: Organiza los elementos en una rejilla rectangular uniforme de filas y columnas.

    5. Proyecto Final Integrador

    El proyecto final consiste en la creación de una aplicación de escritorio completa integrando las 3 capas esenciales: **Controladores de Interfaz Gráfica**, **Modelos de POO** y **Manejo de Eventos/Archivos**.

    import javax.swing.*;
import java.awt.event.*;

public class MiVentanaSimple extends JFrame {
    public MiVentanaSimple() {
        setTitle("Proyecto GUI Java");
        setSize(300, 200);
        setDefaultCloseOperation(EXIT_ON_CLOSE);

        JButton btn = new JButton("¡Hacer Clic!");
        btn.addActionListener(e -> JOptionPane.showMessageDialog(this, "¡Evento ejecutado con éxito!"));

        add(btn);
        setVisible(true);
    }
}

    💻 Código Completo Ejecutable en Java Swing

    import javax.swing.*;
import java.awt.*;
import java.awt.event.*;
import javax.sound.sampled.*;
import java.io.File;

public class MonkeyBodyApp extends JFrame {

    private JLabel lblStatus;

    public MonkeyBodyApp() {
        setTitle("Interactive Monkey Parts - Repaso Swing");
        setSize(400, 500);
        setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
        setLayout(new BorderLayout());

        lblStatus = new JLabel("Click on any monkey part!", SwingConstants.CENTER);
        lblStatus.setFont(new Font("Arial", Font.BOLD, 16));
        add(lblStatus, BorderLayout.NORTH);

        MonkeyPanel monkeyPanel = new MonkeyPanel();
        add(monkeyPanel, BorderLayout.CENTER);

        setVisible(true);
    }

    class MonkeyPanel extends JPanel {
        public MonkeyPanel() {
            addMouseListener(new MouseAdapter() {
                @Override
                public void mouseClicked(MouseEvent e) {
                    int x = e.getX();
                    int y = e.getY();

                    if (x >= 150 && x <= 250 && y >= 40 && y <= 140) {
                        triggerSound("Head", "sounds/head.wav");
                    } else if (x >= 80 && x <= 140 && y >= 160 && y <= 220) {
                        triggerSound("Hand", "sounds/hand.wav");
                    } else if (x >= 260 && x <= 320 && y >= 160 && y <= 220) {
                        triggerSound("Hand", "sounds/hand.wav");
                    } else if (x >= 120 && x <= 170 && y >= 320 && y <= 380) {
                        triggerSound("Foot", "sounds/foot.wav");
                    } else if (x >= 230 && x <= 280 && y >= 320 && y <= 380) {
                        triggerSound("Foot", "sounds/foot.wav");
                    }
                }
            });
        }

        @Override
        protected void paintComponent(Graphics g) {
            super.paintComponent(g);
            g.setColor(Color.ORANGE);
            g.fillOval(150, 40, 100, 100);
            g.setColor(Color.DARK_GRAY);
            g.fillRect(160, 140, 80, 180);
            g.setColor(Color.ORANGE);
            g.fillOval(80, 160, 60, 60);
            g.fillOval(260, 160, 60, 60);
            g.fillOval(120, 320, 50, 60);
            g.fillOval(230, 320, 50, 60);
        }
    }

    private void triggerSound(String partName, String soundFilePath) {
        lblStatus.setText("Body Part: " + partName);
        playSound(soundFilePath);
    }

    private void playSound(String filePath) {
        try {
            File file = new File(filePath);
            if (file.exists()) {
                AudioInputStream audio = AudioSystem.getAudioInputStream(file);
                Clip clip = AudioSystem.getClip();
                clip.open(audio);
                clip.start();
            }
        } catch (Exception ex) {
            System.out.println("Audio error: " + ex.getMessage());
        }
    }

    public static void main(String[] args) {
        SwingUtilities.invokeLater(() -> new MonkeyBodyApp());
    }
}

    📖 Glosario de Términos Java

    Consulta rápida de conceptos clave del lenguaje:

    Término Concepto y Significado
    JDK Java Development Kit. Conjunto de herramientas de software para desarrollo en Java.

    Sobrecarga Métodos en una misma clase con el mismo nombre pero diferente firma.
